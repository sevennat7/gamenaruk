# 🏝️ เกาะมหาสมบัติทศนิยม (Decimal Treasure Island)

เว็บเกมผจญภัยคณิตศาสตร์แสนสนุกสำหรับนักเรียนชั้น **ประถมศึกษาปีที่ 4 และ 5** เพื่อฝึกฝนทักษะการบวกและลบทศนิยมอย่างเป็นขั้นตอน พร้อมระบบสอนตั้งหลักและจุดทศนิยมให้ตรงกัน (Vertical Alignment Method) รองรับทั้งสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์ ด้วยปุ่มขนาดใหญ่และสีสันสดใส

## 🎮 รายละเอียดระบบเกมและกติกา

1. **การลงทะเบียน**:
   - ผู้เรียนกรอก **ชื่อเล่นหรือฉายานักสำรวจ** และเลือกชั้น (**ป.4** หรือ **ป.5**) ไม่เก็บชื่อ-นามสกุลจริง
2. **การผจญภัย 3 ด่าน (ด่านละ 5 ข้อ)**:
   - 🌲 **ด่านที่ 1: ป่าบวกเลข** — บวกทศนิยม 1–2 ตำแหน่ง (มีทด, ตำแหน่งเท่ากัน และไม่เท่ากัน)
   - 💎 **ด่านที่ 2: ถ้ำลบเลข** — ลบทศนิยม 1–2 ตำแหน่ง (มีกระจาย/ยืม, ผลลัพธ์ไม่ติดลบ, มีการเติม 0 ในตัวตั้ง)
   - 🏰 **ด่านที่ 3: ปราสาทสมบัติ** — บวก-ลบทศนิยมไม่เกิน 3 ตำแหน่ง และโจทย์ปัญหาสถานการณ์ชีวิตจริง (เงิน, ความยาว, น้ำหนัก)
3. **ระบบคะแนนและการลองใหม่**:
   - ตอบถูกครั้งแรก: รับทันที **10 คะแนน**
   - ตอบผิดครั้งแรก: ระบบแสดง **คำใบ้ (Hint)** และให้โอกาสลองตอบใหม่อีก 1 ครั้ง หากถูกรับ **5 คะแนน**
   - หากตอบผิดครบ 2 ครั้ง หรือเมื่อตอบเสร็จ: แสดง **กระดานชอล์กวิธีตั้งหลักทศนิยมให้ตรงกัน** อธิบายทีละขั้นตอน
4. **เกณฑ์การผ่านด่าน**:
   - ต้องได้คะแนนอย่างน้อย **30 จาก 50 คะแนน** ในด่านนั้น
   - หากไม่ผ่าน: สามารถกดเริ่มเล่นด่านเดิมใหม่ได้ทันทีด้วย **ชุดโจทย์ใหม่ที่สุ่มขึ้นมา** (คะแนนไม่สะสมจากการเล่นซ้ำ)
5. **หน้าสรุปผลมหาสมบัติ (เต็ม 150 คะแนน)**:
   - สรุปคะแนนรวมทั้ง 3 ด่าน, อัตราการตอบถูกครั้งแรก
   - **หัวข้อที่ควรฝึกฝนเพิ่มเติม (Diagnostic Recommendations)**: วิเคราะห์จุดที่ผู้เรียนตอบผิดโดยอัตโนมัติ
   - ปุ่มพิมพ์ใบบันทึกผล/เกียรติบัตร (Printable View)
   - ระบบทศนิยมคำนวณด้วยจำนวนเต็มที่ปรับสเกล (Scaled Integer Math) ไร้บั๊กทศนิยมเพี้ยน และยอมรับค่าที่เท่ากัน เช่น `1.5` = `1.50` = `1.500`

## 🗄️ โครงสร้างฐานข้อมูลใน Google Sheets (สร้างอัตโนมัติ)

เมื่อมีการส่งข้อมูลครั้งแรก ระบบ Apps Script จะสร้างแท็บและจัดรูปแบบหัวตารางให้อัตโนมัติ โดยไม่ลบหรือเขียนทับข้อมูลเดิม:

1. **แท็บ `Players` (ข้อมูลผู้เล่น)**:
   - `playerId`: รหัสประจำตัวผู้เล่น
   - `nickname`: ชื่อเล่น/ฉายา
   - `grade`: ระดับชั้น (ป.4 หรือ ป.5)
   - `createdAt`: เวลาที่เริ่มเล่น
2. **แท็บ `Results` (ผลคะแนนรวม)**:
   - `sessionId`: รหัสรอบการเล่น (ใช้ตรวจสอบป้องกันการบันทึกซ้ำซ้อน)
   - `playerId`: รหัสประจำตัวผู้เล่น
   - `score`: คะแนนรวม (เต็ม 150)
   - `totalQuestions`: จำนวนข้อทั้งหมด (15 ข้อ)
   - `correctFirstTry`: จำนวนข้อที่ตอบถูกตั้งแต่ครั้งแรก
   - `completedAt`: เวลาที่จบเกม
3. **แท็บ `Answers` (รายละเอียดคำตอบทุกข้อ)**:
   - `sessionId, questionNo, stage, question, userAnswer, correctAnswer, attempt, isCorrect`

> **ความปลอดภัยและเสถียรภาพ**:
> - มีระบบป้องกัน **Formula Injection**: หากผู้ใช้ป้อนข้อความที่ขึ้นต้นด้วย `=`, `+`, `-`, `@` สคริปต์จะเติม `'` นำหน้าเพื่อป้องกันการทำงานเป็นสูตร
> - มีระบบ **Offline Cache**: หากเครือข่ายขัดข้อง หรือยังไม่ได้ตั้งค่า Web App URL ข้อมูลจะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์ พร้อมปุ่ม **"ส่งข้อมูลใหม่"** บนหน้าเว็บ

## 🚀 การนำขึ้น GitHub และตั้งค่าเผยแพร่ผ่าน GitHub Pages

### คำสั่ง Git แบบย่อ:
```bash
# 1. เริ่มต้น Git Repository
git init

# 2. เพิ่มไฟล์ทั้งหมด
git add .

# 3. บันทึก Commit
git commit -m "feat: เพิ่มเกมเกาะมหาสมบัติทศนิยม สำหรับ ป.4-ป.5"

# 4. เปลี่ยนชื่อ branch เป็น main
git branch -M main

# 5. เชื่อมต่อกับ GitHub Repository ของคุณ (เปลี่ยน URL เป็นของคุณ)
git remote add origin https://github.com/USERNAME/decimal-treasure-island.git

# 6. Push ไฟล์ขึ้น GitHub
git push -u origin main
```

### การเปิดใช้งาน GitHub Pages:
1. เข้าไปที่ Repository ของท่านบน GitHub
2. คลิกแท็บ **Settings** ➔ เมนูด้านซ้ายเลือก **Pages**
3. ในส่วน **Build and deployment** > **Branch**:
   - เลือก Branch: `main`
   - เลือก Folder: `/ (root)`
4. กด **Save**
5. รอประมาณ 1–2 นาที หน้าเว็บจะพร้อมใช้งานที่:
   `https://USERNAME.github.io/decimal-treasure-island/`
